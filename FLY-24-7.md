# Бот и ИИ без ПК (Fly.io)

> **Карта РФ:** Fly.io через Stripe обычно **не принимает** российские Visa/Mastercard. Для оплаты в рублях см. **[VPS-RU-24-7.md](VPS-RU-24-7.md)**.

Сейчас ИИ на телефоне зависит от **запущенного ПК** и **cloudflared**. После Fly.io бот и API работают **круглосуточно** по постоянному адресу `https://ИМЯ-ПРИЛОЖЕНИЯ.fly.dev`.

## 1. Установка flyctl

https://fly.io/docs/hands-on/install-flyctl/

```powershell
fly auth login
```

## 2. Деплой из папки backend

```powershell
cd C:\Users\grot-\OneDrive\Desktop\calorie-app\backend
fly launch --no-deploy
```

- Имя: например `calorie-bot` (тогда URL API: `https://calorie-bot.fly.dev`)
- Регион: `ams` (Амстердам)

## 3. Секреты

Подставьте **свои** значения. `PUBLIC_API_URL` = тот же хост, что выдаст Fly (без слэша в конце).

```powershell
fly secrets set `
  BOT_TOKEN="токен_от_BotFather" `
  WEBAPP_URL="https://victormoshkov.github.io/calorie-app/?v=22" `
  PUBLIC_API_URL="https://calorie-bot.fly.dev" `
  AI_PROVIDER="gemini" `
  GEMINI_API_KEY="ключ_с_aistudio.google.com"
```

```powershell
fly deploy
```

Проверка в браузере: `https://calorie-bot.fly.dev/health` → `{"ok":true,...}`

## 4. Обновить адрес ИИ на GitHub Pages

В двух файлах замените cloudflared на Fly:

- `frontend/ai-api.json` → `"apiBase": "https://calorie-bot.fly.dev"`
- `frontend/index.html` → блок `calorie-ai-api-config` (тот же URL)

```powershell
cd C:\Users\grot-\OneDrive\Desktop\calorie-app
git add frontend/ai-api.json frontend/index.html
git commit -m "Point AI API to Fly.io"
git push
```

## 5. BotFather

**Configure Mini App** →  
`https://victormoshkov.github.io/calorie-app/?v=22`

(Параметр `api=` бот может добавлять сам, если задан `PUBLIC_API_URL` на Fly.)

## 6. На телефоне

`/start` → снова «Открыть калькулятор». Внизу **Версия 22**.

---

## Локальный бот на ПК

После Fly **не запускайте** одновременно `python bot.py` на ПК и Fly — будет два polling на один токен. Остановите локальный бот и cloudflared.

## Обновление кода бота

```powershell
cd backend
fly deploy
```

## Лимиты Fly

Бесплатный тариф может «усыплять» машину; первый запрос ИИ иногда дольше. Для личного бота обычно достаточно.
