# База продуктов — как устроена и как расширять

## Не нужно вручную по одному продукту

В приложении **три слоя**:

| Слой | Что это | Объём |
|------|---------|--------|
| **Локальная база** | `foods-local.js` + `foods-local-extra.js` — обычная еда, русские названия | ~120 позиций, растёт файлами |
| **Open Food Facts** | Поиск v1 + v2, русские названия, штрихкод | миллионы упаковок; домашняя еда слабее |
| **Штрихкод** | Тот же OFF по коду EAN на упаковке | хорошо для магазинных товаров |

## Штрихкод и камера

- Кнопка **«Сканировать штрихкод»** — камера телефона (нужен доступ и интернет).
- Можно **ввести цифры** с упаковки или вставить в поиск.
- Если товара нет в OFF — пользователь вводит калории вручную (как в любом дневнике).

## Как сделать базу «как у ХиКи»

1. **Пакетно** — скачать открытые таблицы состава продуктов (справочники РФ) и конвертировать в JSON → добавить в `foods-local-extra.js` или отдельный `foods-ru.json` (тысячи строк, один раз скриптом).
2. **Коммерческий API** — FatSecret Platform (много RU-брендов; ключ на бэкенде, как у ИИ).
3. **Свой сервер** — пользователи добавляют продукты, модерация (как большие приложения).

Ручной ввод нужен только для **редких** позиций, не для всей базы.

## Добавить свои продукты в код

Откройте `frontend/foods-local-extra.js`, добавьте строку:

```js
{ name: "Название", kcal100: 100, protein100: 5, fat100: 2, carbs100: 10, tags: ["синоним"] },
```

`git push` — обновится на GitHub Pages.
